# Component source license audit

This catalog records source licenses. It does not prove which components are in a binary. Main-library default expressions do not replace a review of bundled code, selected files, dependencies, patches, or build settings.

The catalog has 81 component records covering 77 distinct main source inputs.
Seventy-five inputs match the SHA-512 in the VLC 3.0.24 contrib recipes.
x264 and FluidLite use pinned Git commit archives. Their SHA-512 values are measured, not compared to independent release checksums.
The catalog also records 38 separate header, IDL, and potential compiler runtime source files.

## Findings

- **amf**: Headers grant MIT and include a separate notice that AMD does not grant rights to media technology standards. This row covers headers, not a proprietary AMD driver.
- **crystalhd**: Header notice says LGPL version 2.1 without an or-later grant. Header package is not the native driver.
- **d3d11**: All 15 pinned header inputs match recipe SHA512 sums. All 15 corresponding original source IDLs at those same upstream commits explicitly grant LGPL2.1-or-later. Generated header licensing is inferred from this original source relationship; original grant evidence is retained as separate supplemental inputs. This is a compile SDK header dependency, not a separate runtime library.
- **glew**: LICENSE.txt includes BSD-like GLEW and MIT Mesa grants. Its GLEW name-use clause says may be used, unlike the usual BSD3 prohibition; LicenseRef preserves exact text rather than silently correcting it.
- **glib**: Representative glib/garray.c header grants version 2-or-later. Other source files and bundled dependencies can add terms.
- **mysofa**: Default BSD3 grant does not classify separately licensed files/data beneath share and tests. Their license files are retained as evidence.
- **protobuf**: LICENSE identifies separately licensed atomicops generic GCC and POWER files; retain their source notices if compiled.
- **libarchive**: COPYING separately identifies BSD3 files, public-domain archive_parse_date.c, and BLAKE2 files with three alternative licenses. Choose CC0 or Apache2 for those files when applying GPL3. Build scripts have separate terms. Additional compression and crypto dependencies require their own rows.
- **jpeg**: README LEGAL ISSUES supplies IJG grant. Preserve README and binary attribution.
- **aribb24**: Do not infer a GPL3 grant from the top-level COPYING file. src/aribb24.c and src/aribb24/aribb24.h explicitly grant LGPL2.1-or-later.
- **caca**: Default libcaca code grants WTFPL2. Archive also contains LGPL, ISC and GPL licensed files; linkage must exclude or identify those files before treating WTFPL as complete.
- **chromaprint**: LICENSE.md explicitly says bundled FFmpeg code makes the whole library LGPL2.1. External FFT backend license also applies; VLC recipe uses FFmpeg. Later-version grant is from src/avresample/avcodec.h if present; if actual selected code differs, recheck.
- **gcrypt**: AUTHORS grants library LGPL2.1+. LICENSES contains additional BSD/X/OCB and other notices for individual files. Preserve those notices; this row is not the complete expression for all source files.
- **gpg-error**: Library LGPL2.1+; tools carry separate GPL terms and exceptions.
- **goom**: COPYING states only LGPL without a version. LicenseRef preserves that exact grant. Exact LGPL version and source-level exception scope remain unresolved. Do not assign an SPDX version from the filename or recipe.
- **gme**: Default CMake setting selects Nuked YM2612 emulator, LGPL2.1+. MAME alternative grants GPL2-or-later. Record the actual build selection from the build trace.
- **ebml**: README.md identifies bundled utf8-cpp Boost-licensed code, which requires a separate component entry or combined expression.
- **modplug**: COPYING says public domain. No CC0, Unlicense, or other standardized legal instrument is supplied by that statement. Use a LicenseRef with the exact grant if required; do not invent an SPDX license.
- **srt**: MPL2 license choice depends on no applicable Incompatible With Secondary Licenses notice. Inspect actual compiled source notices before asserting GPL secondary-license availability.
- **upnp**: COPYING supplies BSD3; source headers and third-party portions may add terms.
- **ffmpeg**: Default grant from LICENSE.md; optional GPL code requires --enable-gpl; version3 code requires --enable-version3; nonfree configured code may prevent redistribution. Read actual configure invocation before selecting effective license. Recipe alone is not actual-build evidence.
- **gnutls**: Library default LGPL2.1+. lib/minitasn1/libtasn1.h declares bundled ASN1_VERSION 4.20.0. Bundled lib/unistring snapshot files have LGPL2.1+ headers but no established standalone version. lib/inih is BSD3; lib/crau is MIT. Nettle/GMP add their separate dual-license obligations.
- **live555**: liveMedia/include/liveMedia.hh explicitly grants LGPL3-or-later; do not downgrade to LGPL2.1 from historic versions.
- **freetype2**: LICENSE.TXT supplies FTL or GPL2+ choice. Additional BDF/PCF/hash MIT-like, gzip Zlib and copied HarfBuzz code terms apply; docs/FTL.TXT must be retained if FTL is selected.
- **harfbuzz**: COPYING text matches SPDX MIT-Modern-Variant. Other subdirectory COPYING files apply to their own files.
- **fontconfig**: COPYING matches SPDX HPND-sell-variant; it is not the MIT template.
- **opus**: COPYING also links royalty-free patent grants. Those grants must be considered separately from the BSD3 copyright expression.
- **flac**: BSD3 applies to libFLAC/libFLAC++ code. Tools and documentation have separate GPL/LGPL/GFDL terms.
- **vpx**: Default BSD3 copyright grant plus PATENTS conditions. third_party code has separate notices.
- **aom**: Default BSD2 copyright grant plus PATENTS conditions. third_party source licenses are recorded in archive evidence; the actual compiled subset needs build evidence.
- **lame**: libmp3lame/lame.c explicitly grants LGPL2-or-later. VLC LAME_CONF disables decoder; shipped source also contains separately licensed mpglib decoder code.
- **x264**: Same source used for x26410b. Source headers grant GPL2-or-later. No commercial license is assumed.

## Coverage limits

The conditional module source map also names `xau`, `xcb-proto`, `xorg-macros`, and `xproto`.
Their source inputs were not retrieved from the inspected hosts, so this catalog has no license records for those candidates.
The map includes conditional branches from other platforms. It does not establish that these four components occur in the Windows or macOS binaries.
Their missing rows remain explicit. The catalog must not be described as a complete license expression for every candidate binary.
