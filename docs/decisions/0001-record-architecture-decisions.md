# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-10-14

## Context

Agents and humans both change this repository. They need the reasons for past decisions, not only the result.

## Decision

Record significant decisions as short ADRs in `docs/decisions/`, numbered in sequence.

## Consequences

A pull request that changes architecture, tooling, or licensing adds or supersedes an ADR.
